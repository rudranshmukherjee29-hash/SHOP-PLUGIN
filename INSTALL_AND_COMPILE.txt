FAQ
================================================================================

Q: What if the build fails (red X)?
A: Click the failed build and read the error. It will tell you what's wrong.
   99% of the time it's just a network hiccup - try again.

Q: Can I compile it locally without GitHub?
A: Yes, but it's extra work. If you want to:
   - Install Java 25: https://www.oracle.com/java/technologies/downloads/
   - Open terminal in this folder
   - Run: chmod +x gradlew && ./gradlew shadowJar
   - Jar appears in: build/libs/ShopPlugin.jar
   
Q: How big is the jar?
A: About 5-8 MB (it includes all dependencies bundled inside)

Q: Do I need to do anything else?
A: Nope. Just drop ShopPlugin.jar into your server's plugins/ folder and restart.
